# CSV / Excel Cleaner

A practical tool for cleaning messy spreadsheet data.

## Features

- Remove duplicate rows
- Remove empty rows
- Strip extra spaces from text
- Fill empty cells
- Works with CSV and Excel files (Python version)
- Web version for quick CSV cleaning
- Download cleaned files

## Live Demo

[Try the web version here](https://csv-excel-cleaner-4c5911.netlify.app/)

## How to Use (Python)

1. Run the script
2. Enter the path to your CSV or Excel file
3. Choose cleaning options
4. The cleaned file is saved automatically

## Project Structure

- Python version (CSV + Excel support)
- Web version (CSV support)
